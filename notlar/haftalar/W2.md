## 00. JavaScript Temelleri (W2/topics/00_Fundamentals_of_JavaScript.html)

**Ana fikir:** JS, Brendan Eich'in 1995'te Netscape'te yarattığı high-level, interpreted (pratikte JIT-compiled) bir dil. TC39 komitesi ECMAScript spesifikasyonu olarak standartlaştırır (`:14-17`).

**Anahtar kavramlar**
- Motorlar (engines): V8, SpiderMonkey, JavaScriptCore, Chakra. Runtime'lar: tarayıcı, Node.js, Deno, Bun (`:17`).
- Nerede çalışır: Browser (client-side), Node.js (server-side), Mobile (React Native, Ionic, NativeScript), Desktop (Electron, Tauri), Embedded/IoT, otomasyon (Deno, Bun) (`:24-29`).
- Kilometre taşları (`:36-40`):
  | Yıl | Olay |
  |---|---|
  | 1995 | LiveScript, Netscape'te çıktı; adı JavaScript oldu |
  | 1997 | ECMAScript 1, standartlaşma başlar |
  | 2009 | ES5: JSON, strict mode, array helpers |
  | 2015 | ES2015 (ES6): classes, modules, arrow functions, promises |
  | 2017 ve sonrası | Yıllık sürümler: async/await, optional chaining, top-level await |
- Dil özellikleri (Core Language Traits) (`:48-79`):
  - **Case sensitive**: `totalScore` ile `totalscore` farklı. Konvansiyon: değişken/fonksiyon camelCase, class PascalCase, sabit ALL_CAPS.
  - **Dynamic typing**: tip runtime'da belirlenir; `typeof` ve strict equality kullan.
  - **Prototype-based**: nesneler doğrudan başka nesnelerden kalıtım alır; `class` prototipler üzerine syntactic sugar.
  - **Single-threaded event loop**: tek thread; asenkron iş runtime'ın event loop'una devredilir.
  - **First-class functions**: fonksiyonlar değişkene atanır, argüman olarak geçilir, döndürülür.
  - **Interpreted/JIT-compiled**: motor kodu just-in-time makine koduna derler.
- Temel sözdizimi kuralları (`:87-91`): `const`/`let` kullan, `var`'dan kaçın; ekipte noktalı virgül koy (ASI = automatic semicolon insertion tuzakları); `===` tercih et; yorum `//` ve `/* */`, "neden"i anlat; kodu modül/fonksiyonlara grupla.

**Örnek** (`:97-105`)
```js
const total = 42;
const Total = 7;
console.log(total); // 42
console.log(Total); // 7  (farklı identifier)
const whereAmI = typeof window !== "undefined" ? "browser" : "Node.js";
console.log(`This code is running in the ${whereAmI} environment.`);
// tarayıcıda: "This code is running in the browser environment."
// Node'da:    "This code is running in the Node.js environment."
```
(Bu snippet sayfada sadece gösterilir; `00_fundamentals.js` farklı kod çalıştırır, aşağıya bak.)

- `Object.entries(obj).forEach(([key, value]) => ...)`: entries + parametrede array destructuring (`W2/topics/00_fundamentals.js:9`).

## 01. HTML içinde JavaScript (W2/topics/01_Using_JS_in_HTML.html)

**Ana fikir:** JS HTML'e inline `<script>`, harici dosya (`src`), event handler attribute'u (`onclick`) veya `type="module"` ile eklenir.

**Anahtar kavramlar** (`:18-21`, `:26`)
- **Inline script**: `<script>...</script>` arasında; parser ona geldiği anda çalışır.
- **External script**: `<script src="x.js">`. **`defer`**: script DOM parse edilene kadar bekler (DOM hazır olunca çalışır).
- **Event handler attribute**: `onclick="..."`; bunun yerine `addEventListener` tercih et (separation of concerns: yapı ile davranış ayrı).
- **`<script type="module">`**: ES modules, `import`/`export`.
- **Yerleşim kuralı**: bloklayan scriptleri `<body>` sonuna koy veya `<head>`'de `defer` kullan; `<head>`'de inline script sadece kritik konfigürasyon / feature detection için.

**`01_using_js_in_html.js` davranışı** (konsol çıktısı yok, DOM değişir)
- `button?.addEventListener(...)`: optional chaining, buton yoksa hata atmaz (`W2/topics/01_using_js_in_html.js:5`).
- Her tıkta `highlighted = !highlighted` (toggle). `true` ise arka plan `#fde68a`, metin "Inline styles were updated from an external script!"; `false` ise `#f3f4f6` ve "Watch my background color change!" (`:6-10`).

**Dikkat**
- Sayfadaki "inline script head'de çalışır" demosu bozuk: açılış etiketi `<script>` yerine `<p>` yazılmış (`W2/topics/01_Using_JS_in_HTML.html:8`), bu yüzden `"Hello from inline JavaScript!"` konsola düşmez. Üstelik HTML parser `<head>` içinde `<p>` görünce head'i kapatıp body açar: kod metni sayfanın en üstünde düz paragraf olarak **görünür**, sahipsiz `</script>` yok sayılır. Bkz. Hatalar bölümü.
- Sayfa önerisi: butona `onclick="alert('Hi')"` ekleyip inline handler'ı dene, sonra kaldırıp harici script'e dön (`W2/topics/01_Using_JS_in_HTML.html:40`).

## 03. Variables and Constants (W2/topics/03_Variables_and_Constants.html)

**Ana fikir:** Modern JS'de `let` ve `const` block-scoped; `var` function-scoped ve legacy. Varsayılan `const`, yeniden atama gerekiyorsa `let`, `var` yok (`:15-17`, `:147-154`).

**Anahtar kavramlar**
- **`let`**: block-scoped, reassign edilebilir (`:15`, `:35-45`).
- **`const`**: binding kilitli (reassign yok, `TypeError: Assignment to constant variable`), ama gösterdiği object/array **mutate** edilebilir: `person.age = 26`, `numbers.push(4)` serbest (`:16`, `:51-60`).
- **`var`**: function-scoped ve hoisted; `if` bloğu içinde tanımlanan `var` fonksiyonun her yerinden görünür (`:17`, `:65-75`).
- **Hoisting**: `var` bildirimi yukarı taşınır ve `undefined` ile başlar: `console.log(hoistedVar); // undefined (ReferenceError değil)` (`:77-78`).
- **TDZ (Temporal Dead Zone)**: `let`/`const` tanım satırına gelinene kadar erişilemez; erişim `ReferenceError` (`typeof` ile bile) (`:21`, `:106-110`).
- **Global scope**: en dışta tanımlanan `let`/`const`/`var` script içinde her yerden erişilir (`:115-122`).
- **Strict mode** (modüllerde varsayılan) kazara global oluşmasını engeller; her zaman önce bildir (`:18`).
- **İsimlendirme**: değişken camelCase (`userName`, `isUserActive`), sabit UPPER_CASE (`MAX_USERS`, `API_BASE_URL`), açıklayıcı isim (`userCount` iyi, `x` belirsiz) (`:133-142`). Değişkeni kullanıldığı yere yakın bildir (`:155`).

**Karşılaştırma tablosu** (`:166-171`)
| Keyword | Scope | Reassignable? | Redeclarable? |
|---|---|---|---|
| `let` | Block | Yes | No |
| `const` | Block | No | No |
| `var` | Function | Yes | Yes |

Bloktaki `let modern` sadece dış `modern`'i **gölgeler** (shadowing); bloktan çıkınca dıştaki `"let inside global"` geri gelir, `catch` hiç çalışmaz (`W2/topics/03_variables_constants.js:35-39`).
- `hoistingExample()` önce kendi satırlarını loglar, döndürdüğü "Hoisting demo completed." en son loglanır (`W2/topics/03_variables_constants.js:53`, `:56-75`). `const` yeniden atama hatası `constant = ...` dış `const constant`'a gider (blok bitmiştir), runtime `TypeError` (`W2/topics/03_variables_constants.js:46-50`).
- Hata mesajları Chrome/V8 metnidir; Firefox farklı metin verir (emin değilim, tarayıcıya göre değişir).

**Dikkat**
- Demodaki "global" etiketleri yanıltıcı: değişkenler click handler (arrow function) içinde, yani gerçekte function scope (`W2/topics/03_variables_constants.js:8-15`).
- Sayfadaki TDZ örneği: `typeof myVar` → `"undefined"` (var hoist), `typeof myLet` → `ReferenceError` (`W2/topics/03_Variables_and_Constants.html:107-108`). `typeof` normalde bildirilmemiş isimde bile hata atmaz, TDZ'deki isim istisnadır.
- Ders "let ... not hoisted" diyor (`:35`); doğrusu: `let`/`const` da hoist edilir ama initialize edilmez, TDZ bundan doğar. Bkz. Hatalar.

**Ana fikir:** 7 primitive tip + reference (object) tipler. Primitive'ler by value kopyalanır ve immutable; reference tipler pointer kopyalar, mutasyon tüm referansları etkiler (`:15-17`, `:28`, `:34`, `:109`).

**Primitive types (7)** (`:15`, `:36-104`)
| Tip | Örnek | Not |
|---|---|---|

| `number` | `25`, `19.99`, `1.23e4` (=12300), `Infinity`, `NaN` | tamsayı ve ondalık tek tip, double-precision floating-point |
| `boolean` | `true`, `false` | |
| `null` | `let user = null` | bilinçli "değer yok" (intentional absence) |

| `typeof 42` | `"number"` |
| `typeof true` | `"boolean"` |

| `typeof undefined` | `"undefined"` |
| `typeof Symbol()` | `"symbol"` |

## 05. Operators and Expressions (W2/topics/05_Operators_and_Expressions.html)

**Ana fikir:** Aritmetik, karşılaştırma, mantıksal, atama ve özel operatörler; strict karşılaştırma tercih edilir, `+` string ile coercion yapar, öncelik parantezle netleştirilir (`:15-21`).

**Aritmetik** (`:36-50`), `a = 10, b = 3`: `a+b` 13, `a-b` 7, `a*b` 30, `a/b` 3.333..., `a%b` 1 (modulus/remainder), `a**b` 1000 (exponentiation). `"5"+3` ve `5+"3"` → `"53"`; `"5"-3` → 2.

**Karşılaştırma** (`:60-76`)
- Strict: `5 === "5"` → false (farklı tip). Loose: `5 == "5"` → true (type coercion!).
- `NaN === NaN` → **false**; `isNaN(NaN)` → true.
- `null === undefined` → false; `null == undefined` → **true**.

**Mantıksal / short-circuit** (`:85-103`)
- `&&` ilk falsy değerde durur; `||` ilk truthy değerde durur; `!` tersler.
- `user.name || "Anonymous"` → "John"; `user.age && user.age >= 18` → true.
- **`??` (nullish coalescing)**: sadece `null`/`undefined` ise sağ tarafı alır. `config.timeout = null` iken hem `?? 5000` hem `|| 5000` → 5000, "ama davranış farklı" (`:102-103`).
  - (ders dışı ek bilgi) Fark: `0 ?? 5000` → 0, `0 || 5000` → 5000. `||` tüm falsy değerlerde (0, "", false, NaN) varsayılana düşer, `??` düşmez.

**Atama** (`:113-126`): `x=10`; `+=5`→15; `-=3`→12; `*=2`→24; `/=4`→6; `%=5`→1; `**=3`→1.
- Post-increment `counter++` eski değeri döndürür sonra artırır; pre-increment `++counter` önce artırır sonra döndürür. Sırayla: 0→1 (döner 0), →2 (döner 2), →1 (döner 2), →0 (döner 0).

**Özel operatörler** (`:136-154`): ternary `cond ? a : b` (chained ternary okunabilirlik için kaçın); `typeof`; `instanceof` (`date instanceof Date` ve `date instanceof Object` → true); `in` (`"name" in person` → true, `"city" in person` → false).

**Operator precedence** (`:164-183`)
- `2 + 3 * 4` → 14; `(2 + 3) * 4` → 20.
- `true || false && false` → **true** (`&&`, `||`'dan önce); `(true || false) && false` → false.
- `a = b = 5` → ikisi de 5 (atama sağdan sola).
- Dersin sırası (yüksekten düşüğe): `() [] .` > `! typeof ++ --` > `* / %` > `+ -` > `< <= > >=` > `=== !==` > `&&` > `||` > `? :` > `= += -= *= /= %=`.

## 06. Control Flow (W2/topics/06_Control_Flow.html)

**Ana fikir:** Program akışını koşullarla yönetmek: `if/else`, `switch`, ternary, truthy/falsy, guard clause (`:15-18`, `:27`).

**Anahtar kavramlar**
- **if / else if / else**: karmaşık koşullar ve boolean ifadeler için. Örnek: `score = 85` → "Grade: B" (`:47-56`).
- **Nested conditions** yerine **guard clause (early return)**: önce olumsuz durumda `return`, sonra ana iş (`:62-81`).
- **switch**: aynı değeri birçok seçenekle karşılaştırırken. `break` unutulursa sonraki case'e düşer (fall-through); boş case'leri gruplamak için kasıtlı kullanılır (`"Tuesday"`, `"Wednesday"`, `"Thursday"` → "Mid week") (`:91-110`). `default` hiçbiri eşleşmezse. `grade = "B"` → "Passing grade" (`:112-127`).
- **switch vs if/else**: sabit değer listesi (rol: admin/moderator/user) → switch; aralık karşılaştırması (sıcaklık > 30, > 20 ...) → if/else. `temperature = 25` → "Warm weather" (`:133-157`).
- **Ternary**: basit atamalar için; karmaşık mantık için if/else (`:166-189`).
- **Falsy değerler** (`:17`, `:199-206`): `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN`. Geri kalan her şey truthy.

## 08. Functions and Arrow Functions (W2/topics/08_Functions_and_Arrow_Functions.html)

**Ana fikir:** Fonksiyon tanımlamanın yolları (declaration, expression, arrow, IIFE) ve farkları; pure function, closure, higher-order, composition (`:15-18`).

**Anahtar kavramlar**
- **Function declaration**: hoist edilir, tanımdan önce çağrılabilir: `console.log(hoistedFunction()); // "I'm hoisted!"` (`:32`, `:52-55`).
- **Default parameters**: `function greetWithDefault(name = "World")` → "Hello, World!" (`:46-50`).
- **Rest parameters**: `function sum(...numbers)` → `sum(1,2,3,4)` = 10 (`:61-65`).
- **Destructuring parameters**: `function displayUser({ name, age, city })`; varsayılanlı: `createProfile(name, { age = 18, city = "Unknown" } = {})` → `createProfile("Alice")` = `{ name: "Alice", age: 18, city: "Unknown" }` (`:67-76`).
- **Function expression**: değişkene atanmış fonksiyon; hoist edilmez; callback ve koşullu fonksiyon üretimi için (`:82-110`). **Named function expression**: `const factorial = function fact(n) {...}` → `factorial(5)` = 120 (`fact` adı sadece içeride geçerli).
- **IIFE (Immediately Invoked Function Expression)**: `(function(){ ... })();` hemen çalışır; **module pattern** ile private değişken: `myModule.increment(); myModule.getValue()` → 1 (`:116-132`).
- **Arrow function** sözdizimi (`:142-161`): `(a, b) => a + b`; tek parametrede parantez opsiyonel `x => x*x`; parametresizde `() => "Hello!"`; block body'de `{ ... return ... }` gerekir.
- **Arrow vs regular** (`:16`, `:138`, `:167-186`):
  | Özellik | Regular function | Arrow function |
  |---|---|---|
  | `this` | çağrı şekline göre (method'da nesne) | kendi `this`'i yok, dış scope'tan alır (lexical `this`) |
  | `arguments` | var | yok (`ReferenceError` örneği) |
  | Hoisting | declaration hoist olur | hoist olmaz (değişkene atanır) |
  | Uygun kullanım | object methods | callback, array methods, event handler, `setTimeout` |
  - `obj.regularFunction()` → "Regular function this: MyObject"; `obj.arrowFunction()` → ders "undefined" diyor (sınavda dersin cevabı: arrow `obj`'yi `this` olarak görmez, `this.name` "MyObject" **olmaz**; ortama göre gerçek çıktı için bkz. Hatalar).
  - Object method'u arrow yazma: `` greet: () => `Hello, I'm ${this.name}` `` kötü; `greetProperly: function() {...}` iyi (`:203-209`).
- **Sayfadaki diğer çıktılar**: `greet("John")` → "Hello, John!"; `calculateArea(5, 3)` → 15; `greetWithDefault("Alice")` → "Hello, Alice!"; `sum(10, 20)` → 30; `displayUser(user)` → "John is 30 years old and lives in New York"; `multiply(3, 4)` → 12; `calculator.add(5, 3)` → 8; `operation(5)` → 10 veya 15 (`Math.random`); IIFE'ler "I run immediately!" ve "Hello, World!" basar; arrow `add(2, 3)` → 5, `square(4)` → 16, `sayHello()` → "Hello!", `greet("John", "Doe")` → "Hello, John Doe!", `processArray([1, 2, 3])` → `[2, 4, 6]` (`:36-161`).
- **Higher-order function**: fonksiyon döndüren/alan fonksiyon. `createMultiplier(2)(5)` → 10, `createMultiplier(3)(5)` → 15 (`:219-227`).
- **Closure**: iç fonksiyon dış değişkeni (`count`) hatırlar: `counter()` → 1, 2, 3 (`:229-239`).
- **Pure function**: aynı girdiye aynı çıktı, side effect yok (`add`). **Impure**: dış değişkeni değiştirir (`addToTotal` → `total += value`) (`:18`, `:241-250`).
- **Composition**: `square(multiplyByTwo(addOne(3)))` = ((3+1)*2)² = **64**; generic `compose = (...fns) => (value) => fns.reduceRight((acc, fn) => fn(acc), value)`; `compose(square, multiplyByTwo, addOne)(3)` → 64 (sağdan sola uygulanır) (`:256-265`).

**Ana fikir:** Array'ler sıralı, zero-indexed, mutable koleksiyonlar. Mutate eden metotlar (push, splice) ile kopya döndürenler (slice, map) ayrımı; spread/rest, destructuring, map/filter/reduce (`:15-18`).

**Oluşturma** (`:36-48`)

**Destructuring** (`:72-89`)

let [first, second, third] = [1,2,3,4,5]; // 1 2 3
let [a, , c] = numbers;                   // 1 3 (eleman atlama)
let [head, ...tail] = numbers;            // 1, [2,3,4,5] (rest)
let [x, y, z = 10] = [1, 2];              // 1 2 10 (default)
let a = 1, b = 2; [a, b] = [b, a];        // swap → 2 1

**Ekleme/çıkarma** (`:98-118`)
| Metot | Ne yapar | Mutate? | Dönüş |
|---|---|---|---|
| `push(x)` | sona ekle | evet | yeni length |
| `unshift(x)` | başa ekle | evet | yeni length |
| `pop()` | sondan çıkar | evet | çıkan eleman (`"orange"`) |
| `shift()` | baştan çıkar | evet | çıkan eleman (`"grape"`) |
| `splice(1, 1, "cherry", "date")` | index 1'den 1 sil, ekle | evet | silinenler `["banana"]` |
| `slice(1, 3)` | 1'den 3'e (3 hariç) kopya | **hayır** | `["cherry","date"]` |
(push/unshift dönüş değeri ders dışı ek bilgi.)

**Concat ve spread** (`:123-138`): `arr1.concat(arr2, arr3)` ≡ `[...arr1, ...arr2, ...arr3]`; araya ekleme `[...arr1, "middle", ...arr2]`; klon `[...arr1]` ve `cloned === arr1` → **false** (farklı referans).

**Spread vs Rest** (`:16`): aynı `...` sözdizimi. **Spread** açar (`[...arr]`, kopyalama/birleştirme). **Rest** toplar (`function fn(...args)`, `const [first, ...rest] = arr`).

**Chaining** (`:174-191`): top students → `["Bob", "Diana"]`. Ortalama (yaş > 19): ders 87.5 diyor, doğrusu **86.33...** (bkz. Hatalar).

Sayı için `sort((a, b) => a - b)` artan → `[1,5,10,25,40,1000]`; `b - a` azalan → `[1000,40,25,10,5,1]`.

- `flat()` 1 seviye: `[1,2,3,4,[5,6]]`; `flat(2)` → `[1,2,3,4,5,6]`.

## 10. ES6 Modules and Imports (W2/topics/10_Modules_and_Imports.html)

**Ana fikir:** ES modules kodu dosyalar arasında standart şekilde paylaştırır: encapsulation, dependency yönetimi, tree-shaking (`:15`, `:27`).

**Modül özellikleri** (`:18`, `:36-39`)
1. Otomatik **strict mode**.
2. Kendi scope'u var (global değil): modülde `let`/`var` bile `window`'a düşmez (`:63-67`).
3. **Bir kez çalışır**; sonraki import'lar cache'lenmiş instance'ı kullanır.
4. Sadece `export` edilenler dışarıdan erişilir (`:72-73`).
- Tarayıcıda yerel dosyaları **göreli yol** (`./`, `../`) ile import et (`:17`). HTML'de `<script type="module" src="...">` (`:323`). Bundler'lar (Vite, Webpack) ve Node ESM aynı modele uyar (`:21`).

**Default vs Named export** (`:16`, `:42-57`, `:84-126`)
| | Named export | Default export |
|---|---|---|
| Sayı | modül başına çok | modül başına **bir** |
| Export | `export const PI = ...;` `export function add(){}` `export { a, b }` | `export default Calculator;` |
| Import | `import { PI, square } from './math.js'` (isim aynı olmalı, süslü parantez) | `import Calculator from './calculator.js'` (süslü parantez yok, istediğin ad: `import Calc from ...`) |
| Yeniden adlandırma | `import { square as sq } from ...` | zaten serbest ad |
| Karışık | `import logger, { VERSION, formatDate } from './utils.js'` (default önce) | |
- Namespace import: `import * as Math from './math.js'` → `Math.PI`, `Math.square(6)` = 36 (`:96-98`).

**Re-export / aggregating (barrel)** (`:133-144`)
```js
export { add, subtract } from './basic-math.js';
export { add as plus } from './basic-math.js';        // yeniden adlandırarak
export * from './basic-math.js';                       // hepsini (default hariç)
export { default as Calculator } from './calculator.js'; // default'u named yap
export { Calculator as default } from './calculator.js'; // named'i default yap
```
("`export *` default'u içermez" ders dışı ek bilgi.)

## Hızlı tekrar tabloları

**== vs ===**
| | `==` (loose / abstract equality) | `===` (strict equality) |
|---|---|---|
| Tip dönüşümü | yapar (coercion) | yapmaz |
| `5 == "5"` / `5 === "5"` | true | false |
| `null == undefined` / `===` | true | false |
| Öneri | kaçın | tercih et (`W2/topics/00_Fundamentals_of_JavaScript.html:89`) |

**?? vs ||**
| | `??` | `\|\|` |
|---|---|---|
| Sağa ne zaman geçer | sol `null` veya `undefined` ise | sol herhangi bir falsy ise |
| `null ?? 5000` / `null \|\| 5000` | 5000 | 5000 |
| `0 ?? 5000` / `0 \|\| 5000` (ders dışı) | 0 | 5000 |

**Hoisting özeti**
| Bildirim | Hoist | Tanımdan önce erişim |
|---|---|---|
| `var` | evet, `undefined` ile | `undefined` |
| `let` / `const` | TDZ (ders "not hoisted" diyor) | `ReferenceError` |
| function declaration | evet, tamamıyla | çağrılabilir |
| function expression / arrow | hayır (değişken kuralına tabi) | `const`/`let` ile `ReferenceError` (TDZ); `var` ile `TypeError: ... is not a function` (değer `undefined`) |

## Olası sınav soruları ve kısa cevaplar

1. **What is the difference between `let`, `const` and `var`?** `let`: block, reassign var, redeclare yok. `const`: block, reassign yok, redeclare yok (object içeriği değişebilir). `var`: function scope, reassign ve redeclare var, hoist edilip `undefined` ile başlar. Kaynak: `W2/topics/03_Variables_and_Constants.html:166`
2. **What is the Temporal Dead Zone?** `let`/`const` bildirimine kadar olan bölge; erişim `ReferenceError` verir (`typeof myLet` bile). Kaynak: `W2/topics/03_Variables_and_Constants.html:108`
3. **03 demosunda bloktan sonra `legacy` ne yazar, `modern` ne yazar?** `legacy`: "var hoisted to function/global scope" (var ezildi); `modern`: "let inside global" (blok `let`'i sadece gölgeledi, hata yok). Kaynak: `W2/topics/03_variables_constants.js:33`
4. **List the 7 primitive types.** string, number, boolean, null, undefined, symbol, bigint. Kaynak: `W2/topics/04_Data_Types.html:15`
5. **Primitive vs reference: kopyalama farkı?** Primitive değer kopyalanır; reference tipte pointer kopyalanır, mutasyon tüm referanslara yansır. Kaynak: `W2/topics/04_Data_Types.html:17`
6. **`typeof null` ve `typeof []` nedir?** İkisi de `"object"`; null quirk, array için `Array.isArray`. Kaynak: `W2/topics/04_Data_Types.html:189`
7. **Çıktı?** `"5" + 3`, `"5" - 3`, `true + 1` → `"53"`, `2`, `2`. Kaynak: `W2/topics/04_Data_Types.html:162`
8. **`==` vs `===` farkı? `null == undefined`?** `==` coercion yapar, `===` tip+değer karşılaştırır. `null == undefined` true, `===` false. Kaynak: `W2/topics/05_Operators_and_Expressions.html:76`

## Materyalde hata / eksik / güncel olmayan bilgi

1. **Bozuk inline script etiketi.** `<head>` içinde açılış etiketi `<script>` yerine `<p>` yazılmış, kapanış `</script>` (`W2/topics/01_Using_JS_in_HTML.html:8-11`). Sonuç: "Hello from inline JavaScript!" konsola düşmez, kod metni sayfada paragraf olarak görünür, sayfadaki "inline scripts execute as soon as the browser encounters them" kanıtı (`:37`) çalışmaz.
2. **Yanlış ortalama.** Yaşı 19'dan büyükler: Alice 85, Charlie 78, Diana 96 → 259 / 3 = **86.33...**; ders `// 87.5` diyor (`W2/topics/09_Arrays_and_Iteration_Methods.html:191`). (07'deki tüm öğrenciler ortalaması 87.75 doğru: `W2/topics/07_Loops_and_Iteration.html:249`.)
3. **Aynı blokta yeniden `let` bildirimi.** `let [a, , c] = numbers;` (`W2/topics/09_Arrays_and_Iteration_Methods.html:77`) ve aynı örnek bloğunda `let a = 1, b = 2;` (`:87`): birlikte çalıştırılırsa `SyntaxError: Identifier 'a' has already been declared`.
4. **"let is not hoisted" ifadesi teknik olarak eksik.** `W2/topics/03_Variables_and_Constants.html:35`. `let`/`const` hoist edilir ama initialize edilmez; TDZ bu yüzden var (dersin kendisi `:21`'de TDZ'yi anlatıyor). Sınavda "TDZ" cevabı güvenli.
5. **Arrow `this.name` sonucu ortama bağlı.** Ders `// undefined` diyor (`W2/topics/08_Functions_and_Arrow_Functions.html:173`, `:177`). Klasik tarayıcı script'inde üst seviye `this` = `window` ve `window.name` varsayılan `""` olduğundan çıktı "Arrow function this: " (boş) olur; Node CommonJS dosyasında üst seviye `this` = `module.exports` (`{}`) olduğundan `undefined`; ES module'de (veya Node ESM'de) üst seviye `this` = `undefined` olduğundan `this.name` **`TypeError`** atar. Dersin "undefined" cevabı sadece CommonJS'te doğru. (ders dışı ek bilgi)
6. **`arrowFunc(1, 2, 3); // Error`** yanlış: arrow içindeki `arguments` satırı yorumda (`W2/topics/08_Functions_and_Arrow_Functions.html:183`), çağrı hiçbir şey yapmaz, hata atmaz (`:186`).
7. **Eksik ifade.** `instanceof Date; // true for Date objects` sol operand'sız, geçersiz sözdizimi; doğrusu `value instanceof Date` (`W2/topics/04_Data_Types.html:201`).
8. **Regex'te çift backslash.** HTML'de `/\\s+/g` ve `/[^\\w-]/g` olarak görünüyor (`W2/topics/10_Modules_and_Imports.html:171`); HTML backslash kaçışı yapmadığından öğrenci çift `\\` görür. Doğrusu `/\s+/g`, `/[^\w-]/g`. Yazıldığı haliyle `/\\s+/` boşluğu değil "bir backslash + bir veya daha çok `s`" dizisini eşler; `/[^\\w-]/` ise backslash, `w` ve `-` dışındaki **her** karakteri siler (slug neredeyse boş kalır).
9. **Var olmayan named export'u default yapma.** `export { Calculator as default } from './calculator.js';` (`W2/topics/10_Modules_and_Imports.html:144`), oysa `calculator.js` sadece `export default Calculator` yapıyor (`:111`); named `Calculator` yok, link aşamasında `SyntaxError`. Sözdizimi örneği olarak doğru, bu dosya kombinasyonuyla değil.
10. **`process.env` tarayıcıda yok.** Config örneği (`W2/topics/10_Modules_and_Imports.html:156`, `:159`) tarayıcı modülünde `ReferenceError: process is not defined` verir; Node veya bundler gerekir. (ders dışı ek bilgi)
11. **`import * as Math`** global `Math` nesnesini gölgeler (`W2/topics/10_Modules_and_Imports.html:96`); kötü isim seçimi.
