## 1. React Native'e Giriş ([`W4/1-react-native-intro.md`](../../1_hoca_notlari/W4/1-react-native-intro.md))

**Ana fikir:** React Native (RN), React'in bileşen (component) mantığını mobil platformlara taşıyan, tek kod tabanından (single codebase) iOS ve Android uygulaması üreten açık kaynak framework'tür. Kurulum için iki yol vardır: Expo (başlangıç için önerilen) ve React Native CLI (tam native kontrol).

### Ders hedefleri (Lesson Objectives) [`W4/1-react-native-intro.md:3-7`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/1-react-native-intro.md?plain=1#L3-L7)
- RN mimarisini ve çalışma prensiplerini anlamak
- Expo ve React Native CLI ile temel kurulum
- İlk mobil uygulama iskeletini oluşturup çalıştırmak
- Platforma özgü özellikler ve tasarım prensiplerine giriş

### Önceki haftaların özeti [`W4/1-react-native-intro.md:9-14`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/1-react-native-intro.md?plain=1#L9-L14)

| 2 | JavaScript ve ES6 temelleri | RN'in dil temeli |

### React Native nedir? [`W4/1-react-native-intro.md:16-24`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/1-react-native-intro.md?plain=1#L16-L24)
- Facebook (Meta) tarafından **2015**'te geliştirilen açık kaynak (open-source) mobil framework.
- **Cross-platform:** tek kod tabanıyla iOS + Android.
- **Native Performance:** JavaScript bridge üzerinden gerçek native bileşenlere erişim.
- **Hot Reloading:** kod değişikliğini anında görme.
- **Rich Ecosystem:** binlerce 3. parti kütüphane, topluluk desteği.
- **Platform-specific APIs:** kamera, GPS, sensör gibi cihaz özelliklerine erişim.

### Teknik mimari (Technical Architecture) [`W4/1-react-native-intro.md:26-30`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/1-react-native-intro.md?plain=1#L26-L30)
- **JavaScript Thread:** React mantığı ve state yönetimi burada çalışır.
- **Bridge:** JavaScript ile native kod arasındaki iletişim köprüsü.
- **Native Thread:** platforma özgü UI bileşenlerinin render edildiği katman.

### Mimari temeller (3 thread) [`W4/1-react-native-intro.md:41-44`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/1-react-native-intro.md?plain=1#L41-L44)
- **JavaScript Thread:** React mantığı ve UI güncellemeleri hesaplanır.
- **Shadow Thread:** layout hesaplamaları, **Yoga** motoru ile yapılır.
- **Native Main Thread:** native bileşenlerin işlenmesi ve kullanıcı etkileşimleri.
- Not: Kaynakta iki ayrı liste var; ilki Bridge'i, ikincisi Shadow Thread'i (Yoga) anlatıyor. Sınavda "3 thread" sorulursa ikinci liste: JS, Shadow, Native Main.
- (ders dışı ek bilgi) RN 0.76'dan beri varsayılan "New Architecture": Bridge yerine **JSI** (JavaScript Interface), render için **Fabric**, native modüller için **TurboModules**. Kaynak bundan hiç bahsetmiyor.

### React (web) vs React Native [`W4/1-react-native-intro.md:32-39`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/1-react-native-intro.md?plain=1#L32-L39)
| Konu | React (web) | React Native |
|---|---|---|
| Hedef platform | Web | iOS ve Android |
| UI oluşturma | DOM | Native bileşenler (`View`, `Text`, `ScrollView`) |
| Stil | CSS | Flexbox benzeri stil nesneleri (style objects) |
| Navigasyon | React Router | React Navigation (3. parti) |
| Build | Webpack / Vite | Metro bundler + Xcode / Android Studio |

Eşleme (kaynaktaki bileşen listesinden çıkarım, [`W4/1-react-native-intro.md:129`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/1-react-native-intro.md?plain=1#L129)): `div` yerine `View`, `p`/`span` yerine `Text` (RN'de metin mutlaka `<Text>` içinde olmalı, ders dışı ek bilgi), `img` yerine `Image`, `input` yerine `TextInput`, CSS dosyası yerine `StyleSheet.create` ile JS nesnesi.

## 3. Değişkenler ve Sabitler: var / let / const ([`W4/3-react-native-variable-const.md`](../../1_hoca_notlari/W4/3-react-native-variable-const.md))

**Ana fikir:** RN, JavaScript'in değişken tanımlama yollarını kullanır. `const` değişmeyecek değerler, `let` değişen değerler için; `var` eski yöntem, kullanılmamalı.

### Karşılaştırma tablosu [`W4/3-react-native-variable-const.md:35-42`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/3-react-native-variable-const.md?plain=1#L35-L42)
| Özellik | var | let | const |
|---|---|---|---|
| Yeniden tanımlanabilir (Redeclarable) | Evet | Hayır | Hayır |
| Yeniden atanabilir (Reassignable) | Evet | Evet | Hayır |
| Kapsam (Scope) | Function | Block | Block |
| Hoisting (kaynağa göre) | Evet | Hayır | Hayır |

Not: Kaynak let/const için hoisting "yok" diyor; teknik olarak hoist edilirler ama TDZ (Temporal Dead Zone) yüzünden tanımdan önce erişilemezler (bkz. hata bölümü). Sınavda kaynak tablosu sorulursa kaynaktaki cevabı ver, açıklama istenirse TDZ'yi ekle.

### Örnek 1: VariableExample [`W4/3-react-native-variable-const.md:100-177`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/3-react-native-variable-const.md?plain=1#L100-L177)

### Örnek 2: DynamicVariableExample [`W4/3-react-native-variable-const.md:217-378`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/3-react-native-variable-const.md?plain=1#L217-L378)

### Scope örneği [`W4/3-react-native-variable-const.md:380-407`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/3-react-native-variable-const.md?plain=1#L380-L407)

- `if` bloğu dışında `blockVar` ve `blockConst` erişimi **hata** (ReferenceError) (`:404-405`); `functionVar` fonksiyon içinde her yerde çalışır (`:403`).

### Best practices [`W4/3-react-native-variable-const.md:409-453`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/3-react-native-variable-const.md?plain=1#L409-L453)
1. `const` tercih et (`var` kötü).
2. Anlamlı isimler: `maxRetryCount`, `isUserLoggedIn` iyi; `x`, `flag` kötü.
3. Değişkenleri başta (ve değer vererek) tanımla.
- Özet: const = değişmeyen, let = değişen, var = kullanma, const/let block scope.

### Dikkat / tuzaklar

### State özellikleri [`W4/5-react-native-state.md:312-355`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/5-react-native-state.md?plain=1#L312-L355)

2. Güncelleme (`:325-336`):
   - Yanlış: `count = count + 1;` (doğrudan değiştirme)
   - Doğru: `setCount(count + 1);`

|---|---|

### useEffect [`W4/6-react-native-hooks.md:238-401`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/6-react-native-hooks.md?plain=1#L238-L401)
- Bileşen mount (yüklenme), update (güncelleme) veya unmount (kaldırılma) olduğunda çalışan kod yazmayı sağlar (`:240`).
- **Bağımlılık dizisi (dependency array):**
  - `[]` boş dizi → sadece ilk yüklemede bir kez çalışır (`:234`, `:256`).
  - `[isRunning]` → ilk render'da ve `isRunning` her değiştiğinde çalışır (`:329`).
  - (ders dışı ek bilgi) dizi hiç verilmezse her render'dan sonra çalışır.
- **Cleanup function:** effect'in döndürdüğü fonksiyon; bileşen kaldırılınca (ve effect yeniden çalışmadan önce) çalışır (`:235`, `:328`).

**WelcomeMessage** ([`W4/6-react-native-hooks.md:243-277`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/6-react-native-hooks.md?plain=1#L243-L277)):
- `useState('Loading...')`; `useEffect(() => { setTimeout(() => setMessage('Welcome!'), 2000) }, [])`.
- Ekran: önce "Loading...", 2 saniye sonra "Welcome!" (`:221`, `:228-230`).

**Timer** ([`W4/6-react-native-hooks.md:310-401`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/6-react-native-hooks.md?plain=1#L310-L401)):
- State: `seconds` (0), `isRunning` (false) (`:316-317`).
- Effect (`:319-329`): `isRunning` true ise `setInterval(() => setSeconds(seconds => seconds + 1), 1000)`; `return () => clearInterval(interval)` cleanup; deps `[isRunning]`.
- Functional update şart: effect sadece `isRunning` değişince yeniden kurulur; `setSeconds(seconds + 1)` yazılsaydı interval hep ilk `seconds` değerini görür, sayaç 1'de takılırdı (stale closure, ders dışı ek bilgi).
- Start → `setIsRunning(true)`, Stop → `setIsRunning(false)` (effect cleanup ile interval temizlenir), Reset → `seconds` 0 ve durdur (`:331-336`).
- Cleanup bellek sızıntısını (memory leak) önler (`:301`).
- Ekran: "{seconds} seconds", yeşil Start, kırmızı Stop, gri Reset.

### Hook kuralları (Hook Rules) [`W4/6-react-native-hooks.md:403-407`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/6-react-native-hooks.md?plain=1#L403-L407)
1. Hook'ları sadece fonksiyon bileşenlerinde kullan.
2. Hook'ları her zaman bileşenin **en üst seviyesinde** (top level) çağır.
3. Koşul (`if`), döngü veya iç içe fonksiyon içinde hook çağırma.
- (ders dışı ek bilgi) Sebep: React hook'ları çağrı sırasıyla eşler; sıra render'lar arasında değişirse state karışır. Custom hook'lar (`use` ile başlayan) içinde de hook çağrılabilir.

### Özet [`W4/6-react-native-hooks.md:409-414`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W4/6-react-native-hooks.md?plain=1#L409-L414)
`useState`: state yönetimi; `useEffect`: yan etkiler (side effects: API çağrıları, timer); hook'lar fonksiyon bileşenlerini güçlü yapar.

### Dikkat / tuzaklar
- WelcomeMessage'ta cleanup ve console.log anlatılıyor ama kodda yok (bkz. hata bölümü).
- `setInterval` her zaman cleanup ile temizlenmeli.
