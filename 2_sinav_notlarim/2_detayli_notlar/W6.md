**Örnek 2: Responsive Grid with onLayout** ([`W6/components/View.md:79-135`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W6/components/View.md?plain=1#L79-L135)): `onLayout` ile genişlik ölçülür, 500'den büyükse satır başına 3, değilse 2 kart.
```jsx
const [cardsPerRow, setCardsPerRow] = useState(2);
<View onLayout={(event) => {
  const { width } = event.nativeEvent.layout;
  setCardsPerRow(width > 500 ? 3 : 2);
}}>
  <View style={{ flexDirection: 'row', flexWrap: 'wrap', gap: 16 }}>
    {COURSES.map((title) => (
      <View key={title} style={{ width: `${100 / cardsPerRow - 4}%` }}>...</View>
    ))}
```

const loadPage = useCallback(async (pageToLoad, isRefresh = false) => {

- **FlatList Örnek 2 sonsuz yeniden yükleme döngüsü** ([`W6/components/FlatList.md:132-151`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W6/components/FlatList.md?plain=1#L132-L151)): `loadPage`, `useCallback(..., [loadingMore, refreshing])` olduğu için bu iki state her değiştiğinde yeni referans alır; `useEffect(() => { loadPage(1, true); }, [loadPage])` her yeni referansta yeniden çalışır. Trace: (1) ilk effect `loadPage(1, true)` -> `setRefreshing(true)`; (2) yeni referans, effect tekrar çalışır ama guard `if (loadingMore || refreshing) return;` ([`W6/components/FlatList.md:134`](https://github.com/zeki-ozen/MobileAppDevelopment/blob/7a13069/W6/components/FlatList.md?plain=1#L134)) durdurur; (3) 600 ms sonra ilk çağrı biter, `setRefreshing(false)` -> yine yeni referans -> effect `loadPage(1, true)` -> (1)'e döner. Sonuç: yaklaşık her 600 ms'de sayfa 1 yeniden yüklenir, refresh göstergesi sürekli döner; `onEndReached` ile eklenen sayfalar da bitişte (`loadingMore` false) sayfa 1'e sıfırlanır. Doğrusu: ilk yükleme `useEffect(() => { loadPage(1, true); }, [])` ile bir kez, veya guard'lar `useRef` ile tutulup `loadPage` bağımlılıksız yapılır. (statik trace; kod çalıştırılmadı)
