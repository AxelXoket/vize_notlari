# Week 9 — Camera, Notifications, and Maps (Expo + Snack)

This week covers three common mobile capabilities in React Native using Expo:

- **Camera** with `expo-camera` (including runtime permission handling)
- **Notifications** with `expo-notifications` (including runtime permission handling)
- **Maps** with both `react-native-maps` and a Leaflet-based alternative (Leaflet in `react-native-webview`)

Each note starts with a short concept/prop overview and then provides **two runnable examples** designed for **Expo Snack**.

## Snack Setup Notes
- In Snack, add packages from the **Dependencies** panel (instead of running installs locally).
- If you run locally, prefer `npx expo install ...` so versions match your Expo SDK.
